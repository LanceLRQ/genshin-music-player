# Genshin Music Player

> 通过模拟键盘输入，自动演奏《原神》乐器的桌面工具。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

> ⚠️ **项目处于开发早期**：目前只有设计文档，还没有可用的版本。下面列出的特性是规划目标，会随开发推进逐步实现。

## 简介

在《原神》里手动弹风物之诗琴等乐器，按键多、节奏难把握，很难弹出完整连贯的曲子。Genshin Music Player 把 MIDI、键盘谱、简谱等乐谱转换成游戏乐器的按键序列，再像真人按键盘一样自动演奏。

它**只模拟键盘输入**：不读写游戏内存、不注入、不修改客户端、不访问游戏进程，也不做任何网络通信。

## 特性（规划中）

- **多种乐谱**：支持 MIDI 文件、社区常见的键盘谱文本、简谱文本，以及 JSON 谱的导入和导出。
- **多种乐器**：内置风物之诗琴、镜花之琴、老旧的诗琴、节庆鼓，以及新的两行乐器；可以自己改键，也可以新建乐器配置。
- **自动适配**：自动推荐移调和八度，处理黑键、超出音域和和弦过密等情况，并显示每条音轨的命中率。
- **多轨**：可以勾选多条音轨合并演奏，也可以单独试听或演奏某一条音轨。
- **试听与可视化**：演奏前可以先试听，虚拟琴键会跟着高亮，试听到的就是实际会弹出来的。
- **演奏控制**：开始前倒计时、全局热键、变速、节奏人性化、从指定位置播放和区间循环。
- **安全保护**：游戏窗口不在前台时自动暂停并松开所有按键，避免往其他程序里乱打字。

## 平台支持

| 平台 | 支持情况 |
|---|---|
| Windows | 目标平台，支持实际演奏。需要**以管理员身份运行**，否则系统会拦截发给游戏的按键 |
| macOS / Linux | 可以导入乐谱、适配和试听，但**不能向游戏发送按键**（《原神》PC 版不支持这两个平台） |

## 安装

暂无发布版本。首个版本发布后，会在 [Releases](https://github.com/LanceLRQ/genshin-music-player/releases) 提供 Windows 安装包。

从源码构建（工程搭建完成后可用）需要 Node.js 24、pnpm 11 和 Rust stable：

```bash
git clone https://github.com/LanceLRQ/genshin-music-player.git
cd genshin-music-player
pnpm install
pnpm tauri dev
```

## 使用

规划中的基本流程：

1. 导入乐谱（MIDI、键盘谱、简谱或 JSON 谱）。
2. 选择目标乐器，勾选要演奏的音轨，按需调整软件推荐的移调参数。
3. 点击"试听"确认效果。
4. 在游戏里打开乐器界面，回到软件点击"演奏"，在倒计时结束前切回游戏窗口。
5. 随时可以按热键暂停或停止（默认 `F9` 开始/暂停，`F10` 停止）。
