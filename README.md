# Genshin Music Player

> 通过模拟键盘输入，自动演奏《原神》乐器的桌面工具。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

## 简介

Genshin Music Player 把 MIDI、键盘谱、简谱等乐谱转换成《原神》乐器的按键序列，像真人敲键盘一样自动演奏。

它**只模拟键盘输入**：不读写游戏内存、不注入、不修改客户端、不访问游戏进程，也不做任何网络通信。

## 特性

- **多种乐谱**：支持 MIDI 文件、社区常见的键盘谱文本、简谱文本，以及 JSON 谱的导入和导出；文本乐谱可以直接粘贴，`.txt` 文件会自动猜测是简谱还是键盘谱。
- **多种乐器**：内置 12 件乐器（风物之诗琴、镜花之琴、老旧的诗琴、沃雅妮莎、悠可琴、余音、谐律键琴、跃律琴、晚风圆号、荒泷·盛世豪鼓、聚聚鼓、绮筵之鼓）；悠可琴与余音是和弦吉他（第一排为和弦键）。可以在界面里改键、新建乐器、导入或导出 JSON 配置。
- **自动适配**：自动推荐移调和八度，处理黑键、超出音域和和弦过密等情况，适配结果显示命中率和每一类丢音的原因与调整建议。
- **多轨**：可以勾选多条音轨合并演奏，也可以单独试听或演奏某一条音轨；合并多轨时同一个键上的同音只按一次，不算丢音。
- **试听与可视化**：演奏前可以先用内置的合成音色试听，虚拟琴键跟着高亮，试听到的就是实际会弹出来的；乐器预览卡可以在键帽视图和落音（音符下落）视图之间随时切换。
- **演奏控制**：开始前倒计时、全局热键（默认 `F9` 开始/暂停、`F10` 停止，可在设置里修改）、变速（0.5–2.0 倍）、节奏人性化、从指定位置播放和区间循环。
- **模拟发声**：设置 → 演奏里的开关（默认关闭）。开启后「演奏」和全局热键不再向游戏发键，改由本窗口用合成音色直接发声，相当于整曲试听；适合纯试听、没有发键权限（macOS）或不想向游戏发键的场景。
- **安全保护**：游戏窗口不在前台时自动暂停并松开所有按键，避免往其他程序里乱打字；未以管理员身份运行时会有明确提示。

## 平台支持

| 平台 | 支持情况 |
|---|---|
| Windows | 目标平台，支持实际演奏。需要**以管理员身份运行**，否则系统会拦截发给游戏的按键 |
| macOS | 支持实际演奏，但需要先授予**辅助功能权限**（见下方说明） |
| Linux | 可以导入乐谱、适配和试听，但**不能向游戏发送按键**（《原神》PC 版不支持该平台） |

### macOS 说明

- 发键通过系统 CGEvent 接口，**辅助功能权限是硬性前提**，否则按键会被系统静默丢弃：请到"系统设置 → 隐私与安全性 → 辅助功能"勾选本应用。未授权时应用顶部会出现横幅提示，附"去系统设置授权"和"重新检测"按钮；此时点"演奏"也会明确报错，不会静默失败。
- 《原神》PC 客户端没有 macOS 版，macOS 上的实际场景是浏览器里的云原神。
- 游戏窗口识别规则与 Windows 不同：按**前台应用名**（如 Google Chrome、Safari）或**窗口标题**与"设置 → 游戏窗口识别 → 窗口标题"列表精确匹配，类名不参与。默认列表（原神 / Genshin Impact）在 mac 上匹配不到浏览器，使用云原神请把所用浏览器的应用名加进该列表。
- 按**窗口标题**匹配需要 macOS 的**屏幕录制权限**（macOS 10.15 起读取其他应用的窗口标题受此限制）；拿不到窗口标题时仍能按前台应用名匹配，不受影响，所以推荐按应用名（如 Google Chrome）配置。

## 安装

首个版本发布后，将在 [Releases](https://github.com/LanceLRQ/genshin-music-player/releases) 提供 Windows 安装包。安装后**右键以管理员身份运行**——普通权限下系统会拦截发给游戏的按键，游戏完全收不到；软件会在顶部提示并提供「以管理员身份重启」按钮。

从源码构建的方法见[开发文档](docs/development.md)。

## 使用

1. **导入乐谱**：打开 MIDI（`.mid`/`.midi`）、键盘谱或简谱文本、JSON 谱文件，也可以把文件直接拖进窗口，或者粘贴键盘谱/简谱文本。
2. **选择目标乐器，勾选要演奏的音轨**：软件会自动推荐移调和八度偏移，也可以手动调整；每条音轨会显示单独适配时的命中率。
3. **点击"试听"**：确认效果，虚拟琴键会跟着高亮。命中率不理想时，参考适配结果里的丢音原因调整参数，或者换一件目标乐器。
4. **点击"演奏"**：进入倒计时，在倒计时结束前切换到游戏窗口并打开对应乐器的演奏界面；倒计时结束后软件开始自动发送按键。
5. **随时可以按热键暂停或停止**（默认 `F9` 开始/暂停，`F10` 停止），或者切出游戏窗口让软件自动暂停。

各页面的完整功能、参数含义、常见问题的处理见[使用指南](docs/guides/user-guide.md)。
