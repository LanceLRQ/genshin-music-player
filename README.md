# Genshin Music Player

> 通过模拟键盘输入，自动演奏《原神》乐器的桌面工具。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

## 简介

在《原神》里手动弹风物之诗琴等乐器，按键多、节奏难把握，很难弹出完整连贯的曲子。Genshin Music Player 把 MIDI、键盘谱、简谱等乐谱转换成游戏乐器的按键序列，再像真人按键盘一样自动演奏。

它**只模拟键盘输入**：不读写游戏内存、不注入、不修改客户端、不访问游戏进程，也不做任何网络通信。

## 特性

- **多种乐谱**：支持 MIDI 文件、社区常见的键盘谱文本、简谱文本，以及 JSON 谱的导入和导出；文本乐谱可以直接粘贴，`.txt` 文件会自动猜测是简谱还是键盘谱。
- **多种乐器**：内置风物之诗琴、镜花之琴、老旧的诗琴、节庆鼓，以及新的两行乐器；两行乐器上线不久，键位和音高目前是暂定配置，等游戏内实测后会随软件更新校准。可以在界面里改键、新建乐器、导入或导出 JSON 配置。
- **自动适配**：自动推荐移调和八度，处理黑键、超出音域和和弦过密等情况，适配结果显示命中率和每一类丢音的原因与调整建议。
- **多轨**：可以勾选多条音轨合并演奏，也可以单独试听或演奏某一条音轨；合并多轨时同一个键上的同音只按一次，不算丢音。
- **试听与可视化**：演奏前可以先用内置的合成音色试听，虚拟琴键跟着高亮，试听到的就是实际会弹出来的。
- **演奏控制**：开始前倒计时、全局热键（默认 `F9` 开始/暂停、`F10` 停止，可在设置里修改）、变速（0.5–2.0 倍）、节奏人性化、从指定位置播放和区间循环。
- **安全保护**：游戏窗口不在前台时自动暂停并松开所有按键，避免往其他程序里乱打字；未以管理员身份运行时会有明确提示。

## 平台支持

| 平台 | 支持情况 |
|---|---|
| Windows | 目标平台，支持实际演奏。需要**以管理员身份运行**，否则系统会拦截发给游戏的按键 |
| macOS / Linux | 可以导入乐谱、适配和试听，但**不能向游戏发送按键**（《原神》PC 版不支持这两个平台） |

## 安装

首个版本发布后，将在 [Releases](https://github.com/LanceLRQ/genshin-music-player/releases) 提供 Windows 安装包。安装后**右键以管理员身份运行**——普通权限下系统会拦截发给游戏的按键，软件会在顶部提示并提供"以管理员身份重启"按钮。

从源码构建需要 Node.js 24、pnpm 11 和 Rust stable：

```bash
git clone https://github.com/LanceLRQ/genshin-music-player.git
cd genshin-music-player
pnpm install
pnpm tauri dev
```

## 使用

1. **导入乐谱**：打开 MIDI（`.mid`/`.midi`）、键盘谱或简谱文本、JSON 谱文件，也可以把文件直接拖进窗口，或者粘贴键盘谱/简谱文本。
2. **选择目标乐器，勾选要演奏的音轨**：软件会自动推荐移调和八度偏移，也可以手动调整；每条音轨会显示单独适配时的命中率。
3. **点击"试听"**：确认效果，虚拟琴键会跟着高亮。命中率不理想时，参考适配结果里的丢音原因调整参数，或者换一件目标乐器。
4. **点击"演奏"**：进入倒计时，在倒计时结束前切换到游戏窗口并打开对应乐器的演奏界面；倒计时结束后软件开始自动发送按键。
5. **随时可以按热键暂停或停止**（默认 `F9` 开始/暂停，`F10` 停止），或者切出游戏窗口让软件自动暂停。

更完整的操作说明见下面的文档。
