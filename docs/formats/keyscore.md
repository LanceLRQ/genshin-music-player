# 键盘谱语法

键盘谱是社区常见的"字母谱"写法的扩展：每个字母或数字对应乐器上的一个物理按键（按 QWERTY 位置对应），解析时先按"来源乐器"把按键还原成音高或音色，再适配到目标乐器演奏。

## 基本音符

一个字母或数字表示一个音，占一个"步长"（默认 1/2 拍，见下文"指令"）。字母不区分大小写。

```keyscore
Q W E R T Y U
```

连续写多个字母，会依次按步长播放：

```keyscore
QWERTYU
```

## 和弦

圆括号 `()` 或方括号 `[]` 把多个音包起来表示和弦，整个和弦只占一个步长：

```keyscore
(QE) [AD]
```

和弦内部可以有空格，会被忽略：

```keyscore
(Q E U)
```

## 延长与休止

- `-` 把上一个音（或上一个和弦）延长一个步长；在不能持续发声的乐器上，效果等同于休止。
- `/` 休止一个步长。
- `|` 小节线，纯装饰用，解析时直接忽略。

```keyscore
Q - W / E | R
```

## 显式时值

在一个音或和弦后面加 `:` 加一个数字或分数，可以指定它占几个步长（不写默认是 1 个步长）：

```keyscore
Q:2 W:1/2 E
```

```keyscore
(QE):2 W
```

## 指令

指令写成 `@名称=值`，放在文本任意位置，对指令之后的内容生效（`@instrument` 除外）：

| 指令 | 作用 | 默认值 |
|---|---|---|
| `@bpm=120` | 速度（拍/分钟） | `90` |
| `@step=1/2` | 每个符号占几拍，可以写分数或小数 | `0.5` |
| `@instrument=windsong-lyre` | 来源乐器 id；**只能写在第一个音符之前** | 导入对话框选择的乐器，默认风物之诗琴 |

```keyscore
@bpm=100 @step=1/4
Q W E R
```

来源乐器决定字母能弹出什么音（或音色）。下面这份谱用节庆鼓的来源乐器，`F`、`J` 弹出的是敲击音色而不是音高：

```keyscore
@instrument=festive-drum
F J F F J
```

## 空格作为休止

导入对话框里可以打开"空格视为休止"选项：关闭时（默认）空格只是分隔符，不占时值；打开后每个空格都额外占一个步长。这是导入选项，不是文本里的指令，所以本文档的示例都按默认（关闭）来写。

## 注释

`//` 到行尾是注释：

```keyscore
Q W E // 这一行后面是注释，不影响解析
R
```

## 完整示例

一段简单的旋律，开头设置速度和步长，中间有和弦和延长音：

```keyscore
@bpm=110 @step=1/2
Q W E (QW) - /
A S D F
```

用风物之诗琴的键位弹一段带小节线的短旋律（小节线仅用于阅读，不影响时值）：

```keyscore
@bpm=90 @instrument=windsong-lyre
A A D D | F F D - | S S A A | G G F -
```

## 错误示例

来源乐器上不存在这个按键：来源乐器默认是风物之诗琴，它的键位是 `QWERTYU`（高音）、`ASDFGHJ`（中音）、`ZXCVBNM`（低音），不包含 `K`、`I`、`O`、`P` 等字母：

```keyscore-error
// 预期错误: 没有按键「K」
Q K
```

无法识别的字符（键盘谱只认识字母、数字和上面列出的符号）：

```keyscore-error
// 预期错误: 无法识别的字符
Q %
```

和弦没有用 `)` 或 `]` 闭合：

```keyscore-error
// 预期错误: 和弦没有闭合
Q
(QE
```

和弦不能为空：

```keyscore-error
// 预期错误: 和弦不能为空
()
```

`@instrument` 必须写在第一个音符之前，不能中途切换来源乐器：

```keyscore-error
// 预期错误: @instrument 必须写在第一个音符之前
Q @instrument=floral-zither
```

找不到指定的来源乐器：

```keyscore-error
// 预期错误: 找不到来源乐器
@instrument=no-such-instrument
Q
```

指令格式错误，或者取值不合法：

```keyscore-error
// 预期错误: @bpm 必须是正数
@bpm=0
Q
```

```keyscore-error
// 预期错误: @step 写法错误
@step=x
Q
```

显式时值写法错误（分母为 0、负数、或者不是数字/分数）：

```keyscore-error
// 预期错误: 时值写法错误
Q:0
```

## 导入选项一览

在"打开文件"或"粘贴键盘谱"对话框里可以设置：

| 选项 | 说明 | 默认值 |
|---|---|---|
| 来源乐器 | 优先读取文本里的 `@instrument`；没有写时使用这里选的乐器 | 风物之诗琴 |
| BPM | 没有 `@bpm` 时使用的速度 | `90` |
| 步长 | 没有 `@step` 时每个符号占几拍，可选 1/4 拍、1/2 拍、1 拍 | 1/2 拍 |
| 空格视为休止 | 关闭时空格只是分隔符；打开后每个空格占一个步长 | 关闭 |

解析出错时，对话框会显示出错所在的行号、列号，以及那一行的原文和一个指向出错位置的 `^` 标记。
