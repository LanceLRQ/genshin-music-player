# 简谱语法

简谱文本只描述音高和节奏，与目标乐器无关：导入后直接进入适配流程，由适配算法负责把音高映射到具体乐器的按键上。社区流行的简谱记法没有统一标准，本项目用下面这套语法。

## 音级与休止

`1`–`7` 是当前调的大调音级，默认每个占 1 拍；`0` 是休止，同样默认占 1 拍：

```jianpu
1 2 3 4 5 6 7
```

```jianpu
1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 -
```

## 升降号与八度

升号 `#`、降号 `b`写在数字**前面**；`'` 表示升八度，`,` 表示降八度，写在数字**后面**，都可以叠加：

```jianpu
#4 b7 1' 1'' 1, 1,,
```

## 时值：减时线、附点、增时线

- `_` 让时值减半，可以叠加（`__` 是原时值的 1/4）；
- `.` 附点，时值变为原来的 1.5 倍；
- `-` 把前一个音（或前一个和弦）延长 1 拍。

```jianpu
1_ 2__ 3. 4
```

```jianpu
1 - - 2
```

## 和弦

方括号 `[]` 包起来的多个音同时发声；时值标记（`_`、`.`）要写在 `]` 后面，音高本身仍然可以带八度标记：

```jianpu
[135] [1 3 5']_
```

## 三连音

花括号 `{}` 包起来的音，每个时值 ×2/3：

```jianpu
{1 2 3} 4
```

## 指令

| 指令 | 作用 | 默认值 |
|---|---|---|
| `@bpm=100` | 速度 | `90` |
| `@key=D`（也可写成 `1=D`，支持 `bB`、`F#` 这样的升降号写法） | 调号：`1` 对应的音名 | `C` |
| `@octave=4` | 不带八度标记的 `1` 所在的八度 | `4`（即 `1` = C4） |
| `@track=右手` | 开始一个新音轨，新音轨的时间从 0 开始；写在文本最开头时只是给默认音轨改名 | 不写时所有音都在同一条音轨 |

```jianpu
@bpm=120 @key=D
1 2 3 4 5 6 7
```

```jianpu
@track=右手
1 2 3
@track=左手
1, 2, 3,
```

## 小节线与注释

`|` 纯装饰，解析时忽略；`//` 到行尾是注释：

```jianpu
1 2 | 3 4 // 这是注释
5 6 7 1'
```

## 完整示例

《小星星》开头几句，C 大调、90 拍/分钟（省略 `@bpm` 也是这个速度）：

```jianpu
1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 -
5 5 4 4 | 3 3 2 - | 5 5 4 4 | 3 3 2 -
```

移到 D 大调、带一个八度标记和一个和弦收尾：

```jianpu
@key=D @bpm=100
1 2 3 4 | 5 6 7 1'
[1 3 5]_
```

## 错误示例

无法识别的符号：

```jianpu-error
// 预期错误: 无法识别的符号「x」
1 x
```

三连音不能嵌套，也必须闭合：

```jianpu-error
// 预期错误: 不支持嵌套三连音
{1 {2}}
```

```jianpu-error
// 预期错误: 三连音没有闭合
1
{1 2
```

和弦没有闭合：

```jianpu-error
// 预期错误: 和弦没有闭合
[1 3
```

和弦内不能写时值标记，要写在 `]` 后面：

```jianpu-error
// 预期错误: 和弦内不能写时值
[1_ 3]
```

和弦不能为空：

```jianpu-error
// 预期错误: 和弦不能为空
[]
```

和弦内不能包含休止符：

```jianpu-error
// 预期错误: 和弦内不能包含休止符
[1 0]
```

休止符不能带升降号或八度标记：

```jianpu-error
// 预期错误: 休止符不能带升降号或八度标记
#0
```

升降号后面必须是 1–7 的数字：

```jianpu-error
// 预期错误: 升降号后面应该是 1–7 的数字
#x
```

指令写法或取值错误：

```jianpu-error
// 预期错误: 调号写法错误
@key=H
1
```

```jianpu-error
// 预期错误: @octave 应为 -1 到 8 的整数
@octave=9
1
```

音高超出 MIDI 音高号范围（0–127）：

```jianpu-error
// 预期错误: 音高超出 MIDI 范围
@octave=8
7'''
```

## 导入说明

简谱文本没有"来源乐器"的概念，粘贴或导入后直接可以选择目标乐器进入适配。解析出错时，导入对话框会显示出错所在的行号、列号，以及那一行的原文和一个指向出错位置的 `^` 标记。
