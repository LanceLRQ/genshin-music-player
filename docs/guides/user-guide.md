## 界面总览

软件共有四个页面，通过左侧边栏切换：

| 页面 | 用途 |
|---|---|
| 演奏 | 导入乐谱、选择乐器和音轨、调整参数、试听和演奏——日常使用几乎都在这一页 |
| 乐器 | 浏览内置乐器、新建或编辑自定义乐器、导入导出乐器配置 |
| 设置 | 快捷键、倒计时、模拟发声、游戏窗口识别、日志等全局选项 |
| 帮助 | 软件内置的使用文档：本指南、常见问题、乐器参数速查和乐谱语法 / 配置格式参考 |

侧边栏底部显示后端状态：Windows 和 macOS 的真实发键后端分别显示绿色圆点加「Windows」「macOS」，Windows 还附带管理员权限是否就绪（✓ / ✗）；灰色圆点加「模拟模式」表示当前平台不能向游戏发送按键。演奏进行中，「演奏」导航项上会出现呼吸状态点，方便在其他页面时一眼看到。

侧边栏可以用 Ctrl/Cmd+B 折叠成图标模式。

首次启动时会弹出「使用前请阅读」风险提示，勾选「我已了解上述风险」后才能开始使用。之后可以在 设置 → 关于 → 查看风险提示 重新打开。

顶部出现的红色横幅是环境警告，需要处理后才能正常演奏：

- **「未以管理员身份运行」**（Windows）：点「以管理员身份重启」，或退出后右键以管理员身份运行。
- **「未授予辅助功能权限」**（macOS）：点「去系统设置授权」，在系统设置里勾选本应用后回到软件点「重新检测」。
- **「当前平台不能向游戏发送按键」**：所在平台没有真实发键后端，「演奏」只会模拟执行并记录日志。

## 快速上手

从零到弹出第一首曲子，只需要五步：

1. **导入乐谱**：演奏页点「打开文件」选择 `.mid` 文件，或把文件直接拖进窗口，也可以粘贴键盘谱 / 简谱文本。
2. **选择目标乐器**：左栏「目标乐器」下拉里选你在游戏里要弹的乐器。
3. **勾选音轨**：默认全选非鼓轨。每条音轨右侧的百分比是它单独适配时的命中率，参考它决定留哪些轨。
4. **试听**：点「试听」用本窗口的合成音色听一遍效果，虚拟琴键会跟着高亮；试听到的就是实际会弹出来的。
5. **演奏**：点「演奏」开始倒计时，在倒计时结束前切换到游戏窗口并打开乐器的演奏界面，倒计时结束后自动开始弹。

随时可以按全局热键控制：`F9` 开始 / 暂停 / 继续，`F10` 停止。切出游戏窗口时软件会自动暂停并松开所有按键，切回来后按 `F9` 继续。

## 导入乐谱

软件一次只保留一份乐谱，新导入会替换当前的（演奏进行中不能导入）。支持四种格式、三种导入方式：

### 支持的格式

| 格式 | 扩展名 | 说明 |
|---|---|---|
| MIDI | `.mid` / `.midi` | 最推荐。每个 MIDI 音轨对应软件里的一条音轨，带鼓轨识别 |
| 键盘谱 | `.txt` 或粘贴 | 社区「字母谱」写法，字母对应游戏乐器按键，[语法说明](../formats/keyscore.md) |
| 简谱 | `.txt` 或粘贴 | 数字简谱文本，带调号、八度、时值记号，[语法说明](../formats/jianpu.md) |
| JSON 谱 | `.json` | 软件自己的乐谱格式，任何已导入的乐谱都可以「导出 JSON 谱」存成它 |

`.txt` 文件会按内容自动猜测是键盘谱还是简谱（数字 0–7 占一半以上就猜简谱），猜错的在导入对话框里切换标签页即可。

### 三种导入方式

- **打开文件**：左栏「导入」→「打开文件…」，或按 Ctrl/Cmd+O，或右栏空态里的「打开文件」按钮。
- **拖拽**：把文件直接拖进窗口任意位置，松开即导入。
- **粘贴文本**：左栏「导入」→「粘贴键盘谱… / 粘贴简谱…」，或右栏空态里的对应按钮。

### 文本导入对话框

粘贴键盘谱或简谱时会打开「导入文本乐谱」对话框：左边是文本框，输入后实时解析并显示「解析成功：N 个音，时长 m:ss.s」或具体的出错位置（标出出错行和符号）；右边填标题等参数。解析失败时「导入」按钮不可用，不会导进坏谱。

键盘谱特有的参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 来源乐器 | 风物之诗琴 | 这份键盘谱原本是照着哪件乐器写的，软件据此把字母还原成音高；谱子里写 `@instrument=...` 时以谱面为准 |
| BPM | 90 | 速度，谱面 `@bpm=` 优先 |
| 步长 | 1/2 拍 | 每个字母 / 数字占几拍 |
| 空格视为休止 | 关 | 开启后文本里的每个空格占一个步长的休止 |

如果你手里只有一段音频，先用外部工具转成 MIDI，见[从音频提取 MIDI](audio-to-midi.md)。

## 选择乐器与音轨

### 目标乐器

左栏「目标乐器」下拉分「内置」和「自定义」两组，共内置 12 件乐器，键位均已游戏内实测。名字带「待实测」徽章的乐器（复制出的副本、自建或导入的乐器），键位或音高还没有在游戏里逐键验证过，可能与实际不符——可以正常使用，但建议先试听核对；确认有出入时可以到乐器页自己改，不用等软件更新。

切换目标乐器后，软件会自动重新推荐移调和八度。

### 音轨

音轨列表显示每条轨的信息：

- **勾选框**：勾选的音轨合并成一个整体来适配和演奏；「全选」「全不选」快速切换。多轨合并时，同一时刻重复的音只按一次，不算丢音。
- **鼓徽章与轨道类型**：MIDI 第 10 通道的轨道标「鼓」；写在普通通道上的鼓谱（不少音源这么导出）会按音符分布自动猜测，猜错时点轨道旁的「当鼓 / 当旋律」手动切换，适配立即按新类型重算。
- **描述行**：音符数、音域、首音时间。MIDI 分轨经常没有可读的名字，主要靠音域和首音时间分辨哪条是主旋律。
- **单独命中率**：这条轨单独适配时的命中率，≥95% 绿色、≥80% 琥珀、更低红色；「—」表示这条轨在当前参数下没有可弹的音。
- **单独试听 / 单独演奏**：临时只用这一条轨生成时间线试听或演奏，不改变勾选状态，进行中会在底部显示「单独试听：音轨名」徽章，点 ✕ 结束。

## 读懂适配结果

左栏底部「适配结果」是判断「这首曲子在这件乐器上能不能弹好」的核心：

- **命中率** = (弹出 + 合并) ÷ 总音数。命中率越高，实际听感越接近原曲。
- **弹出 N · 合并 N · 折回 N**：「合并」是同一时刻重复的音只按一次——音高类看键位，敲击类看声音（左右对称键算同一个声音），多轨齐唱时很常见，**不算丢音**；「折回」是超出乐器音域的音被折回音域内弹（移调或换乐器通常可以消除折回）。
- **和弦键 命中 x/y（z%）· 回退 n**：只对悠可琴、余音这类带和弦键的乐器显示。和弦簇命中和弦键会整簇收成一个按键，未命中回退逐音。
- **丢弃 N**：真正弹不出来的音，按原因分类，每类都有调整建议（鼠标悬停查看）：

| 原因 | 含义 | 常见处理 |
|---|---|---|
| 黑键 | 乐器上没有这个半音键 | 改「黑键」策略为「就近取音」，或调整移调 / 换调性匹配的乐器 |
| 超音域 | 超出乐器最低 / 最高音，且策略为「丢弃」 | 改「超音域」为「按八度折回」，或调整八度 / 移调 |
| 复音超限 | 同一时刻的音超过了复音上限 | 提高「复音上限」（前提是乐器弹得过来），或减少同时勾选的音轨 |
| 过密 | 同一个键两次按下间隔小于乐器的最小重复间隔，后一次被丢 | 降低速度、回 MIDI 编辑器量化音符，或换诗琴类乐器 |
| 未映射 | 鼓轨里的音色在乐器配置里找不到对应键 | 在适配参数里给音色指定音符（见下方敲击类说明）；内置鼓已覆盖 GM 35–81 全音域 |

命中率不理想时，优先点「恢复自动推荐」回到算法推荐值，再针对主要丢音原因微调。拿不准往哪个方向调时，点「音符统计」看勾选音轨的音高分布（条形图，可按音高或数量排序），对着乐器的音域选移调和八度。

## 调整演奏参数

右栏「演奏参数」卡片分左右两节。手动改过适配参数后，卡片右上角出现「已手动调整」徽章和「恢复自动推荐」按钮。

### 适配参数（左节）

音高类乐器：

| 参数 | 范围 | 说明 |
|---|---|---|
| 移调 | −11 ~ +11 半音 | 整体升高 / 降低。选让音符落在乐器键位上的值；命中率会实时反映效果 |
| 八度 | −3 ~ +3 | 整体升 / 降八度，配合移调把音域对准乐器 |
| 黑键 | 跳过 / 就近取音 | 乐器的全音阶上没有谱中的半音时：跳过（丢音）还是就近取音 |
| 超音域 | 按八度折回 / 丢弃 | 音超出乐器音域时：折回音域内继续找键，还是直接丢 |
| 复音上限 | 1 ~ 6（高级） | 同一时刻最多同时按几个键。1 相当于只留旋律 |
| 和弦窗口 | 0 ~ 50ms（高级） | 起音时间差在这个范围内的音视为「同一时刻」，参与复音分组 |

敲击类乐器没有移调 / 八度，只有「分界音高」和按声音的音符指定。游戏内鼓的左右键是对称同音的（如聚聚鼓 `Q`/`A` 两侧的底鼓），界面里同一声音合并为一行并标注键位，连续击打时自动左右轮流，把单键连打的间隔上限翻倍——写谱时不用关心用哪一侧。

- **分界音高**（管非鼓轨的音）：默认「自动（中位数）」取所选音轨音高的中位数分界；也可以手动指定（填 `C4` 或 `60` 都行），低于分界线的音映射为「咚」，其余映射为「咔」。
- **指定音符**（每个声音一行下拉，标注对应键位，横向排列自动换行）：导入或切换乐器时会按乐谱的音高统计**自动预填**——数量多的音高优先，落在乐器鼓映射表内的沿用默认映射，表外的按音高分给剩余声音；预填结果直接可用，不满意就改，选回「自动」恢复默认。MIDI 的鼓音符号和默认映射对不上时同样用指定纠正，指定的音符优先于鼓映射表和分界音高，不用复制乐器、改完立即生效。**鼓写在普通音轨上的 MIDI**（如 Splice 音源导出）多数会被自动识别为鼓轨；个别漏网的会整轨按分界音高映射成咚/咔，在咚/咔都不存在的乐器（如聚聚鼓）上全部「未映射」丢弃——把 底鼓、军鼓 等逐个指到谱里实际的音符即可。

### 演奏控制（右节）

| 参数 | 范围 / 默认 | 说明 |
|---|---|---|
| 速度 | 0.50–2.00×，默认 1.00× | 演奏和试听都生效。双击右侧数值快速回到 1.00× |
| 人性化 | 0–30ms | 给每个按键加一点随机时间偏移，听感不那么机械；0 为关闭。导入新谱时的初值取设置里的「默认人性化」 |
| 音量 | 0–100%，默认 70% | **只影响本窗口试听**，与游戏音量无关 |
| 输出 | 系统默认 / 具体设备 | 试听音频的输出设备，只影响试听 |

## 进度条、定位与区间循环

进度条不只是显示进度，它同时是**按键密度热力图**和**定位控件**：

- **热力图**：底部的竖条表示对应时间段的按键密度，越高越密；天蓝色部分是当前演奏区间，灰色部分在区间外。一眼就能看出前奏、主歌、副歌的疏密。
- **点击 / 拖动定位**：在进度条上点击或拖动即可定位——**试听中**立即跳到那个位置继续播；**空闲时**定位的是演奏的起点（也就是把区间起点移过去）。
- **键盘定位**：进度条获得焦点后，`←` / `→` 每次移动 2 秒，`Home` 到开头，`End` 到结尾。
- **演奏进行中**进度条锁定，不能定位。

进度条下方的「区间」一行用来选一段反复练：

- 双柄滑块或两个时间输入框（支持 `m:ss.s` 或纯秒数）设置区间的开始和结束，最短 100ms。
- 「循环」开关打开后，试听和演奏都只在这段里无限循环。
- 「重置区间」按钮恢复整曲。

配合定位和区间可以只循环副歌，或跳过超难段——把区间起点定位到想开始的地方即可。

## 试听

「试听」用本窗口的合成音色（振荡器合成，不使用任何游戏素材）播放**和实际演奏完全相同的时间线**：同样的乐器键位、速度、人性化、区间和循环。试听到的就是实际会弹出来的。

- 试听时虚拟琴键跟着高亮；键帽视图下每颗键帽显示键名和音名（或音色 / 和弦名），点击键帽可以试听单个音——只在本窗口发声，不会向游戏发键。
- 虚拟琴键右上角可以在「键帽视图」和「落音预览」之间切换：键帽视图模拟乐器键盘布局；落音预览是音游式的音符下落画面，列与乐器按键一一对应。
- 试听中可以随时点进度条或用键盘跳转位置；空格开始 / 停止试听，Esc 停止试听。

## 演奏

点「演奏」（或全局热键 `F9`）后的流程：

1. **倒计时**（默认 3 秒，设置里可改 0–10 秒）：虚拟琴键上方显示大号秒数，在结束前切换到游戏窗口、打开乐器的演奏界面。
2. **自动开始**：软件开始按时间线向游戏发键。演奏页底部状态行显示「演奏中」，侧边栏出现状态点。
3. **控制**：`F9` 暂停 / 继续，`F10` 停止；也可以用底部按钮。

演奏中的行为细节：

- **锁定**：从倒计时开始到停止之前，导入、换乐器、选轨、适配参数、区间、速度都不能修改，只能暂停或停止。
- **失去前台自动暂停**：切出游戏窗口（或最小化）时立即暂停并**松开所有按键**，状态行显示红色提示；切回游戏后按 `F9` 或点「继续」恢复。
- **倒计时期间取消**：点「取消」或 `F10`。
- **结束统计**：演奏结束后底部显示「上次演奏：N 次按键 · 延迟 p50 / p95 / 最大 · 变速丢弃 N」，下一行是执行日志文件路径（可一键复制），日志目录也在设置 → 日志里能看到。
- **全局热键被系统独占**：`F9` / `F10` 不会传给游戏。热键可以在设置里改成其他 F1–F12 或带修饰键的组合。

### 模拟发声

设置 → 演奏 → 「模拟发声」（默认关闭）。开启后「演奏」「单独演奏」和全局热键开始 / 暂停**不再向游戏发键**，改由本窗口用合成音色直接发声——相当于整曲试听，状态行会显示「模拟发声」徽标。适合：

- 纯粹想听听效果，不想切游戏；
- macOS 上还没授予辅助功能权限；
- 不想让任何按键发出去。

## 乐器页：管理与自定义

### 浏览

左栏按「内置」「自定义」分组列出乐器，名称旁标注「音高 / 敲击」类型和「已验证 / 待实测」状态（12 件内置乐器均已验证）。选中后右栏显示：

- **虚拟琴键预览**：只读键帽，点击可试听单个音（音高类显示音名、敲击类显示音色、和弦键显示和弦名）。
- **时序信息**：按住时长、最小重复间隔、能否持续发声。这两个毫秒值是「游戏能可靠识别按键」的实测下限，改小可能漏音。
- 敲击类乐器额外显示**鼓映射表**（MIDI 音符号 → 音色，按音色分组、以音名显示）和分界音高。

内置乐器不能直接改，操作是「复制为自定义」「导出 JSON」；自定义乐器多出「编辑」「复制」「导出 JSON」「删除」。

### 新建 / 编辑

「新建」从一个最小模板开始；「编辑」改自定义乐器。编辑器要点：

- **键位捕获**：点键位按钮显示「请按下按键…」，直接按键盘上想要的键即可绑定；不支持的键会提示。每行最多 12 个键，最多 4 行。
- **音高**：填音名（`C4`、`F#3`）或 MIDI 号（`60`）。音高类乐器每个键还可以切到「和弦」模式，填和弦名和 2–7 个构成音。
- **敲击音色**：敲击类乐器的键填音色名（如 `don`、`ka`），同一乐器内不能重复。
- **鼓映射表**：把 MIDI 鼓音符号映射到音色，可一键「恢复 GM 默认映射」再改。
- 所有修改**即时校验**，底部显示「有 N 个校验错误」时保存按钮禁用；「试弹预览」卡片实时反映编辑结果，可以边改边点着听。
- 修改未保存时切走会弹确认框。

### 导入 / 导出

- **导出 JSON**：把乐器配置存成 `<id>.json`，用于备份或分享。
- **导入 JSON**：选择配置文件，校验失败的会列出具体问题；ID 和内置乐器冲突会拒绝，和已有自定义乐器重复时询问是否覆盖。

配置文件的完整格式说明见[乐器配置格式](../formats/instrument-profile.md)。

## 设置页

设置页改完不会立即生效：点底部「保存设置」才保存，「撤销修改」放弃改动。设置分六组：

### 快捷键（全局）

- **开始 / 暂停 / 继续**：默认 `F9`。空闲时开始演奏、演奏中暂停、暂停后继续。
- **停止**：默认 `F10`。任何状态下停止。

全局热键由系统独占注册，游戏本身收不到这些按键。只允许 F1–F12，或带修饰键（Ctrl / Alt / Shift）的字母、数字组合，避免占用打字键。点输入框后直接按下组合键录入。

### 快捷键（窗口内）

- **打开文件**：默认 `Ctrl/Cmd+O`
- **开始 / 停止试听**：默认 `Space`
- **停止试听**：默认 `Escape`

窗口内快捷键只在软件窗口聚焦时生效。注意侧边栏折叠固定占用 `Ctrl/Cmd+B`，别把别的快捷键设成它。五个快捷键两两不能相同，冲突会标红。

### 演奏

| 设置 | 默认 | 说明 |
|---|---|---|
| 倒计时 | 3 秒（0–10） | 点「演奏」后留给你切游戏的时间 |
| 默认人性化 | 0ms（0–30） | 导入新乐谱时「人性化」滑块的初值 |
| 模拟发声 | 关 | 见[演奏 → 模拟发声](#模拟发声) |
| 和弦键匹配 | 开 | 只影响悠可琴、余音等带和弦键的乐器：开启时同一时刻 ≥3 个音级的音符簇会尝试匹配和弦键（整簇一个按键）；关闭后一律逐音按下 |

### 游戏窗口识别

演奏时只有「认定的游戏窗口」在前台才发键，这是防止往别的程序里乱打字的安全机制。

- **Windows**：按窗口类名（默认 `UnityWndClass`）加窗口标题（默认「原神」「Genshin Impact」）同时匹配，两者都要命中。
- **macOS**：类名不参与，按**前台应用名**（如 Google Chrome）或**窗口标题**匹配。玩云原神时，把浏览器的应用名加进标题列表。

右上角「恢复默认」一键还原。

### 日志

- **写入执行日志**：默认开。每次演奏在日志目录生成 `exec-<时间戳>.jsonl`，记录每个按键的目标 / 实际时间和汇总统计，用于排查计时问题。
- **日志目录**：只读路径显示，可复制。

### 关于

平台、后端、管理员状态（仅 Windows）、版本号、数据目录，以及「查看风险提示」按钮。

## 常见问题

**Q：点了「演奏」，游戏里没有任何反应。**

最常见的原因是权限。Windows 必须以管理员身份运行软件（顶部有横幅提示时点「以管理员身份重启」）——普通权限下按键会在系统层被静默丢弃，软件自己也不知道。macOS 需要授予辅助功能权限。其次确认游戏窗口在前台、虚拟琴键覆盖层没有显示「等待切换到原神窗口」。

**Q：试听有声音，演奏没声音。**

检查设置 → 演奏 → 「模拟发声」是不是开着——它会让「演奏」只在本窗口发声、不发键。想真正向游戏演奏就关掉它。

**Q：命中率很低怎么办？**

先看丢音分类（见[读懂适配结果](#读懂适配结果)）：黑键和超音域多就调移调 / 八度或换乐器；过密多就降低速度；复音超限多就减少同时勾选的音轨。多轨合并的曲子也可以只保留主旋律轨。改乱了就「恢复自动推荐」。

**Q：演奏中为什么不能改参数、不能拖进度条？**

演奏时间线在开始前就生成并交给调度器了，中途修改会导致实际按键和进度显示对不上。需要调整时先按 `F10` 停止。想从中间某处开始，空闲时点进度条定位区间起点，再开始演奏。

**Q：切出游戏后为什么自己停了？**

这是安全机制：游戏窗口失去前台时立即暂停并松开所有按键，避免按键发到别的程序里。切回游戏后按 `F9` 继续。

**Q：macOS 上怎么玩云原神？**

1. 授予辅助功能权限（系统设置 → 隐私与安全性 → 辅助功能，勾选本应用）。
2. 设置 → 游戏窗口识别，把浏览器应用名（如 Google Chrome）加进列表。
3. 如果想按窗口标题匹配，还需要屏幕录制权限；一般按应用名匹配就够。

**Q：同一时间好几个音，为什么只按了一次？**

多轨合并时，同一时刻重复的音会被合并成一次按键（适配结果里的「合并」），这不是丢音——那个键按一次，几条轨的声音就都出来了。音高类按键位判断重复；敲击类按声音判断，左右对称键是同一个声音，所以同一拍上的两个底鼓只会敲一下，而不会左右手同时砸下去。

**Q：执行日志在哪里？**

设置 → 日志 → 日志目录（可复制路径）。每次演奏一个 `exec-*.jsonl` 文件，演奏结束时的统计行也直接显示该次日志的路径。

**Q：乐器标着「待实测」，能用吗？**

能用。内置乐器的键位都已在游戏里逐键实测过（12 件均为已验证）；标「待实测」的是复制出的副本或自建 / 导入的乐器，键位或音高可能与游戏实际不符。建议先试听核对；发现不对可以到乐器页直接改键位和音高，或编辑 JSON 后重新导入，不用等软件更新。
