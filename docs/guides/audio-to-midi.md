# 从音频提取 MIDI

Genshin Music Player 不内置音频转 MIDI 的功能，只支持导入 MIDI 文件、键盘谱、简谱和 JSON 谱。如果你只有一段音频（比如一首歌的录音），需要先用外部工具把它转换成 MIDI，再导入到本软件里适配和演奏。这篇指南介绍这个转换流程，以及转换之后怎么清理出适合原神乐器演奏的版本。

> ⚠️ **版权提示**：只处理你拥有版权、已获授权，或者确认属于公有领域的音频。转换出来的 MIDI 文件本身不构成对原始录音版权的规避——公开演奏、发布视频或者分享转换出来的谱面之前，请自行确认你有权这样做。本项目不提供、不内置任何受版权保护的音频或乐谱。

## 整体流程

```
原始音频 → （可选）音源分离 → 转录成音符 → MIDI → 清洗、简化 → 导入 Genshin Music Player
```

原神乐器大多只有一到两个八度、无法弹和弦密集的伴奏，所以流程的重点不是"转录得多准确"，而是"转出来之后怎么简化成一条能弹的旋律线"。

## 第一步（可选）：音源分离

如果音频里同时有人声、伴奏、鼓点，直接转录容易把好几个声部的音混在一起。可以先用音源分离工具把人声（或者你想要的旋律声部）单独提取出来：

| 工具 | 说明 |
|---|---|
| [Demucs](https://github.com/facebookresearch/demucs) | Meta 出品，分离人声、鼓、贝斯、其他伴奏，效果好，依赖 PyTorch，模型体积几百 MB 到几 GB |
| [Spleeter](https://github.com/deezer/spleeter) | Deezer 出品，速度快，模型更轻量，效果略逊于 Demucs |

只需要提主旋律的话，这一步可以跳过，直接对完整混音做转录，后面人工挑一条旋律线出来。

## 第二步：转录成 MIDI

| 工具 | 特点 | 适合的场景 |
|---|---|---|
| [Spotify Basic Pitch](https://github.com/spotify/basic-pitch) | Apache-2.0 开源，模型只有几 MB，有 Python 包和 JS 版（`@spotify/basic-pitch`），可以离线运行，也有[网页版](https://basicpitch.spotify.com/)不用装任何东西 | 大多数情况下的首选，尤其是钢琴、人声哼唱这类单旋律或简单多声部的音频 |
| [ByteDance Piano Transcription](https://github.com/bytedance/piano_transcription) | 专为钢琴优化，转录质量很高 | 钢琴独奏 |
| [MT3（Google Magenta）](https://github.com/magenta/mt3) | 支持多种乐器同时转录，效果强 | 多乐器合奏，但模型较重、上手成本高 |
| [CREPE](https://github.com/marl/crepe) / pYIN | 只做单一基频（音高）追踪，不做和弦 | 只要一条纯旋律线，比如人声哼唱 |
| AnthemScore、Klangio 等商业软件 | 图形界面，开箱即用，一般是付费软件 | 不想接触命令行 |

最省事的路径：打开 [Basic Pitch 网页版](https://basicpitch.spotify.com/)，上传音频，导出 MIDI。命令行版本（Python）大致是这样：

```bash
pip install basic-pitch
basic-pitch ./output-dir ./my-audio.mp3
```

会在 `output-dir` 里生成同名的 `.mid` 文件。

## 第三步：清洗与简化

自动转录出来的 MIDI 几乎不能直接拿来演奏，通常需要在你熟悉的 MIDI 编辑器（比如 MuseScore、Logic、FL Studio，或者任何支持 MIDI 编辑的软件）里做这些处理：

1. **只保留一条旋律线**：多数原神乐器只有一到两个八度、不适合弹密集和声，删掉伴奏、和弦音轨，只留主旋律（可以再留一条简单的低音线）。
2. **量化时值**：自动转录的音符起止时间经常有几十毫秒的抖动，用编辑器的"量化"（quantize）功能对齐到最近的十六分音符或三十二分音符，能明显减少后面适配时因为"过密"被丢弃的音符。
3. **删除过短的误判音符**：转录时偶尔会把泛音、换气声之类的噪声识别成极短的音符，手动检查并删掉这些杂音。
4. **检查音域**：Genshin Music Player 的适配面板会显示每条音轨的音域和自动推荐的移调结果，命中率低的话，先回到 MIDI 编辑器里看看是不是有个别音符跳了很远的音（比如误判高了一个八度），修正后再重新导入。
5. **敲击类乐器**：如果目标是节庆鼓这类敲击乐器，不需要保留具体音高，只需要保留节奏；可以把整条旋律都移到同一个音高上，或者直接手动写一份键盘谱（见 [键盘谱语法](../formats/keyscore.md)）会更省事。

## 第四步：导入

把清洗好的 `.mid` 文件用软件的"打开文件"或者拖拽导入，选择目标乐器，照常进行适配和试听。如果命中率不理想，回到第三步继续调整，或者尝试改用 [简谱](../formats/jianpu.md) / [键盘谱](../formats/keyscore.md) 手动扒一份更精简的谱子。

## 小结

| 你的输入 | 建议路线 |
|---|---|
| 已经有 MIDI 文件 | 直接导入，跳过本指南 |
| 单声部音频（哼唱、单乐器独奏） | Basic Pitch 转录 → 量化 → 导入 |
| 完整混音（人声 + 伴奏） | Demucs 分离出人声或想要的声部 → Basic Pitch 转录 → 简化到单旋律 → 导入 |
| 只想要节奏，不在乎具体音高 | 转录后把音高统一，或者直接手写键盘谱 |
